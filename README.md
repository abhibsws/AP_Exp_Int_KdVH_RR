# Asymptotic-Preserving Exponential Integrators applied to the Hyperbolic Korteweg-de Vries System


This repository contains code to reproduce the results presented in the paper  
*"Asymptotic-Preserving Exponential Integrators applied to the Hyperbolic Korteweg-de Vries System"*  
by Abhijit Biswas, Sebastiano Boscarino, David I. Ketcheson, Giovanni Russo.
